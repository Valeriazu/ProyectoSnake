# Snake Game en Python 🐍🎮

Una versión personalizada del clásico juego Snake desarrollada en Python utilizando la librería **Pygame**. Incluye música de fondo, efectos de sonido y gráficos personalizados (como Pochacco y manzanas).

## 🚀 Características

- **Diseño personalizado:** Utiliza imágenes propias para la serpiente (`pochacohead`), la manzana y el fondo (`pasto.jpg`).
- **Efectos de sonido y música:** Música de fondo continua y sonidos al comer frutas (`ding.wav`) o perder (`ooh.wav`).
- **Sistema de puntuación:** Contador de puntos en tiempo real en la esquina superior derecha.
- **Manejo de colisiones:** Game Over si la serpiente colisiona consigo misma.
- **Controles intuitivos:** Teclas de dirección para moverse, `Enter` para reiniciar y `Esc` para salir.
